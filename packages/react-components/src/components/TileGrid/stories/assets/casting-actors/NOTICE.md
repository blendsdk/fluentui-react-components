# Casting actor portrait assets

These portraits are synthetic images generated by [ThisPersonNotExist.org](https://thispersonnotexist.org/).
They are not photographs of real people.

- Source gallery: https://thispersonnotexist.org/human-face-images/2 (pages 2 through 8)
- Terms of use: https://thispersonnotexist.org/terms-of-use
- Downloaded: 2026-10-27

The source site grants permission to use the generated faces for personal and commercial
purposes and states that it does not claim copyright on them. The images are used here as
development fixtures for the CastingAppMT reference Storybook story. They are not covered by
this repository's MIT license.

All files were centre-cropped to 3:4, resized to 512 x 683 JPEG, stripped of metadata, and
saved with quality 82. No other visual changes were made.
