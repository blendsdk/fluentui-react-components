### Resolution Notes

**AR-1:** Confirmed on 2026-10-17 in the planning conversation. The user selected the option that includes the standalone filler, the overlay and the controller hook.

**AR-2:** Confirmed on 2026-10-17 in response to the artifact-shape question. The feature folder is `codeops/features/loading/`; the RD is `requirements/RD-01-loading-primitives.md`; the plan is `plans/loading/`.

**AR-3:** The user said "I like your latest design" after reviewing the local-hook + normal-component recommendation. The rejected variants were the dynamic `[MyLoading, controller]` tuple and the provider; both were discussed with their tooling and tree-restructuring costs.

**AR-4:** The user approved the design that replaces `busy()` / `done()` with `run()`. The reasons recorded in the design discussion: a thrown operation skips `done()`, overlapping operations hide the loader too early, and a double `done()` underflows. `begin()` was discussed as a future escape hatch but is not part of v1.

**AR-5:** The user approved the blocking overlay semantics for region-level work. The visible overlay appears after 300ms; the content stays mounted and becomes inert; focus moves only when it was inside the covered content and is restored afterwards. The scrim uses the Fluent token; the overlay stays local and does not portal.

**AR-6:** The default is `Loading…` with a blank/whitespace fallback. This matches the repository's `ConfirmDialog` pattern of English defaults plus caller overrides, and fixes the legacy 35/47 unlabeled uses. The label is a plain string, never HTML.

**AR-7:** The standalone filler keeps the legacy visual role (large ring, label below) but drops the v8 opaque body background and `z-index: 999999`. A `minHeight` prop covers empty parents; the component is transparent by default.

**AR-8:** The user approved the scope exclusions in the latest design. They are recorded as Won't Have in RD-01 and are not executable plan work.

**AR-9:** The hook returns a snapshot object. `run` is referentially stable; `isLoading` and `label` change with active operations. A store was considered for render isolation but rejected for v1 because the loader is region-scoped and the repository already uses caller-owned state in this pattern.
