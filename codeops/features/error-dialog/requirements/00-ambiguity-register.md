## Resolution Notes

**AR-1:** Capture, the singleton store and the session policy are framework/app concerns; the
component is controlled and side-effect free. This keeps the library SSR- and test-safe (the
legacy store attached its window listener at import time).

**AR-2:** Feature artifacts live under `codeops/features/error-dialog/`.

**AR-3–AR-14:** Resolved 2026-10-16 in the discovery batch. No complexity escalation was
triggered: the component adds no dependency, no infrastructure and no generalized mechanism; the
copy affordance uses the platform Clipboard API.

**Approved complexity escalations:** None.
